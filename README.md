# EUVpn — macOS indirme

[EUVpn-local.pkg indir](https://github.com/erhanulas/EUVpn-downloads/releases/latest/download/EUVpn-local.pkg)

[Tüm sürümler ve dosya doğrulama özeti](https://github.com/erhanulas/EUVpn-downloads/releases)

Apple Silicon ve macOS 27 veya üstü gerektirir. Paketi açıp macOS yönetici onayıyla kurun. Uygulama `/Applications/EUVpn.app` konumuna kurulur.

Güncelleme öncesi EUVpn bağlantısını kesip uygulamadan çıkın. Yerel imzalı uygulama içerir; Apple Developer ID imzası/notarization bulunmaz.

Bu depo yalnız dağıtım içindir; EUVpn uygulama kaynak kodu ve kişisel VPN profilleri içermez.
